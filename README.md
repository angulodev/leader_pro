# Area Leader Pro

Plataforma de gestión de proyectos para líderes de área. Construida con React + Vite + Supabase.

## Stack
- **Frontend:** React 18 + Vite
- **Base de datos:** Supabase (PostgreSQL) — schema `area_leader`
- **Iconos:** Material Symbols Rounded (Google Fonts)

## Setup local
```bash
git clone https://github.com/angulodev/area-leader-pro.git
cd area-leader-pro
npm install
cp .env.example .env  # completar con credenciales Supabase
npm run dev
```

## Variables de entorno
```
VITE_SUPABASE_URL=https://TU_PROYECTO.supabase.co
VITE_SUPABASE_ANON_KEY=TU_ANON_KEY
```
